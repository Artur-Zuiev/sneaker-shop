# 👟 Sneaker Shop — Demo E-commerce Frontend

A polished and responsive demo storefront built with **vanilla HTML, CSS, and JavaScript**.
Focus: real product flows (catalog → product → cart), modern micro-interactions, and a production-ready UX — all without frameworks.

## ✨ Features

- 🏷 **Catalog** with brand tabs (All/Nike/Adidas/Puma), search, and price sort
- 🖼 **Product page** with gallery (thumbs, arrows), **lightbox** (keyboard, swipe, loop), sizes/colors, and **fly-to-cart animation**
- 🛒 **Cart** with product variants, quantity controls, line totals, and demo checkout
- 🌙 **Dark/Light theme** synced across pages with header toggle
- ♿ **Accessible & responsive** (keyboard navigation, ARIA labels, mobile-first layout)
- ⚡ **No frameworks** — just clean HTML + CSS + JS

---

## 🎨 Design & UX

- Built as a **portfolio-ready e-commerce demo**
- **Clean, modern UI** with subtle animations
- Optimized for **mobile-first experience** (swipe gestures, responsive grid)
- Focused on **accessibility** (keyboard support, ARIA attributes)

## 🚀 Run Locally

1. Clone the repo:

   ```bash
   git clone https://github.com/<YOUR_USERNAME>/sneaker-shop.git
   cd sneaker-shop
   ```

2. Open index.html directly in your browser

3. Run with VS Code Live Server for auto-reload:
   - Right-click index.html
   - Select "Open with Live Server"
