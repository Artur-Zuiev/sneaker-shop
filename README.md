# Sneaker Shop

A responsive **frontend e-commerce demo** built with HTML, CSS and vanilla JavaScript. The project explores the shopping experience from browsing products to managing a cart.

> A portfolio demonstration, not a live store or payment service.

## Highlights

- Product catalog with brand filters, search and sorting
- Product details with image gallery, sizes and colors
- Cart interactions, quantity controls and calculated totals
- Dark and light themes
- Responsive layouts and keyboard-friendly UI controls
- Interactive transitions and micro-animations

## Technology

**HTML5 · CSS3 · JavaScript (no frontend framework)**

## Structure

- `index.html` — catalog
- `product.html` — product details
- `cart.html` — shopping cart
- `about.html` — information page
- `css/` — styling
- `js/` — browser logic
- `data/` — demo product data

## Run locally

```bash
git clone https://github.com/Artur-Zuiev/sneaker-shop.git
cd sneaker-shop
```

Open `index.html` in your browser, or use VS Code Live Server for local development.

## Project scope

This is an independent frontend demonstration. Checkout is for demonstration only; it does not process real payments.
